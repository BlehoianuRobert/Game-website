# GRIDFORGE API
REST API built with Laravel + JWT + Neon (PostgreSQL).

## Prerequisites

**PHP 8.3+**
- Windows: https://windows.php.net/download (Thread Safe zip, add to PATH)
- Mac: `brew install php`
- Linux: `sudo apt install php8.3 php8.3-cli php8.3-mbstring php8.3-xml php8.3-pgsql`

**Composer**
- Windows/Mac/Linux: https://getcomposer.org/download
- Mac/Linux alternative:
```bash
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer
```

Verify both are installed:
```bash
php -v
composer -v
```

## Setup
```bash
cd GRIDFORGE
composer install
cp .env.example .env
# Fill in DB_HOST, DB_DATABASE, DB_USERNAME, DB_PASSWORD, NEON_ENDPOINT
php artisan key:generate
php artisan jwt:secret
php artisan migrate
```

## Run
```bash
php artisan serve
# API runs at http://localhost:8000
```

## API Documentation (Swagger UI)
Open in browser: **http://localhost:8000/api/documentation**
- Click **Authorize** and paste a Bearer JWT (obtained from `POST /api/v1/auth/login`)
- All protected endpoints are marked with the lock icon

The spec source file is at `src/api/openapi.yaml`.
To sync changes into Swagger UI:
```bash
cp openapi.yaml GRIDFORGE/storage/api-docs/api-docs.yaml
```

## Environment variables
| Variable | Description |
|---|---|
| `DB_HOST` | Neon PostgreSQL host |
| `DB_DATABASE` | Database name |
| `DB_USERNAME` | Database username |
| `DB_PASSWORD` | Database password |
| `DB_SSLMODE` | `require` for Neon |
| `NEON_ENDPOINT` | Neon endpoint ID (e.g. `ep-wispy-moon-xxxxxx`) |
| `JWT_SECRET` | Generated by `php artisan jwt:secret` |
| `CACHE_STORE` | `file` (used by ad state machine) |
