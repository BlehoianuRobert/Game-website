# GRIDFORGE API

Laravel 13 REST API for the GRIDFORGE game platform.

## Requirements

- PHP 8.3+
- Composer
- A Neon PostgreSQL database (or any PostgreSQL instance)

## Setup

**1. Clone the repo and navigate to the API folder**
```bash
cd Hackaton/team-7/src/api/GRIDFORGE
```

**2. Install dependencies**
```bash
composer install
```

**3. Copy the environment file**
```bash
cp .env.example .env
```
